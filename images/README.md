# RaspiKVM artwork

`raspikvm-logo.svg` is the current documentation logo. Its switch symbol is original artwork for RaspiKVM. The blue connects it visually to the historical RaspiKey wordmark while the branching screens represent the new host-switching function.

The lettering is outlined from Roboto Regular and Bold supplied by the existing `typeface-roboto` frontend dependency. The SVG needs no external fonts, scripts or network requests.
